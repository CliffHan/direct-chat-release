# direct-chat · website source

This repository holds the source of the **direct-chat website**, not of the app itself — the `isle` app is not open source.

- Site: <https://direct-chat.clifftop.win/en/> 
- Downloads: [GitHub Releases](https://github.com/CliffHan/direct-chat-release/releases)

The site is built with Jekyll and served by GitHub Pages; pushing to `main` publishes it.

## Feedback

Feel free to open an [issue](https://github.com/CliffHan/direct-chat-release/issues) with questions or reports. This is a personal project, so **replies aren't guaranteed to be prompt**. You can also email <cliff@clifftop.win>.
